# 首版需求与边界

首版交付三套独立持久化子系统：院系课程目录、先修关系图、学生成绩与等效协议。各有输入、业务键、版本、裁定和失败反例。目录的同号冲突、图的环路以及学分的撤销是三种不同业务决定，分别有可观察输出；最终资格报告从各账重算，并保存报告历史。

十个决定包含目录来源权威、同号学分争议、停开历史、AND/OR 求值、图环阻断、图适用学年、成绩来源、等效协议、重复抵扣和专业学分类别。三条跨账路径是目录变动使等效重审、停开使新学年图待审、等效撤销使学生资格失效；旧学年证据不可被新学年覆盖。

未实现：培养方案毕业审计、跨校学分协议、短学期学时折算、课程大纲差异比对、教学语言要求、学籍休复学窗口、跨专业名额调剂和双学位共享冲突。首版不能声称已支持这些对象。

## 问卷公开汇总

内部报告与公开汇总分开：内部保留每张答卷 token 的最新有效分数、人数和精确均分；公开只发布匿名 token 组的响应数、总分与按公布精度四舍五入的均分。每次公开申请带版本留档，冻结申请也保留但绝不进入公开结果。

发布门槛不是人数下限，而是以历史公开值为约束的离散反推判定：若新增聚合使任一参与者 1..5 分唯一确定，则冻结；单人独有查询、恰等于下界的分组、均分精度差异、多次重叠查询组合都必须按真实公布值计算。目录停开或同版争议会冻结该 `course_id`、`year` 的后续问卷发布并留下目录证据，目录恢复后可重新申请，历史公开值仍参与约束。未实现：差分隐私噪声、k-匿名分组生成和跨课程联合发布，首版不声称支持。
