# 首版需求与边界

首版交付三套独立持久化子系统：院系课程目录、先修关系图、学生成绩与等效协议。各有输入、业务键、版本、裁定和失败反例。目录的同号冲突、图的环路以及学分的撤销是三种不同业务决定，分别有可观察输出；最终资格报告从各账重算，并保存报告历史。

十个决定包含目录来源权威、同号学分争议、停开历史、AND/OR 求值、图环阻断、图适用学年、成绩来源、等效协议、重复抵扣和专业学分类别。三条跨账路径是目录变动使等效重审、停开使新学年图待审、等效撤销使学生资格失效；旧学年证据不可被新学年覆盖。

未实现：培养方案毕业审计、跨校学分协议、短学期学时折算、课程大纲差异比对、教学语言要求、学籍休复学窗口、跨专业名额调剂和双学位共享冲突。首版不能声称已支持这些对象。

措辞试验只处理问卷试验内部的分配、送达与核证；不替代问卷均分或名册回应率两项独立结果，也不做功效计算、协变量调整或顺序检验之外的替代估计。
